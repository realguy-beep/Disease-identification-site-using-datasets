      INFO

      Model limitations

      Known constraints, dataset issues, and things learned while building this project

      1. Idealized symptom dataset

      The disease prediction model was trained on 132 binary flags from a Kaggle dataset. Real illness presentations are nuanced, with degrees of severity and timelines that binary flags cannot capture. Predictions reflect correlation with the dataset, not clinical diagnoses.

      2. Handcrafted image features

      The eye classifier uses color statistics and edge gradients with an ExtraTrees model instead of a deep convolutional network. It classifies sample photos reasonably well in testing, but is easily thrown off by lighting, skin tone, or camera distance.

      3. Small datasets and class imbalance

      The stroke dataset has only ~4.9% positive cases, which produces false alarms even with balanced class weights. The heart failure (299 rows) and diabetes (768 rows) datasets are relatively small, which limits how well they generalize.

      4. Session logging

      Prediction logs are kept in a local SQLite file (predictions.db). In stateless container deployments without persistent volumes, the log resets when the container restarts.
